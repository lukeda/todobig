# TodoBig

A cross-platform desktop todo application built with Tauri and React.

## Stack
- **Frontend**: React 19, TypeScript, Vite
- **UI**: Mantine components, Tailwind CSS
- **Desktop**: Tauri 2 (Rust)
- **Icons**: Lucide React
- **Storage**: localStorage (Supabase available)

## Features
- Create, complete, and delete todos
- Hashtag support with auto-extraction and color coding
- Automatic tag tracking
- Active/completed task separation
- Chronological sorting

## Development
Run `pnpm dev` to start the Vite dev server with hot reload.

## Build
Run `pnpm build` to create a production build.
